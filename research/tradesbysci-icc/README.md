- Clearly distinguish SCI's actual instruction from developer/engineering assumptions.

- Never treat the initial structural break as sufficient for a complete ICC entry.
- SCI works in NASDAQ, gold, and BTC examples; generalization to all of NORSTRADA's five crypto pairs requires testing.
- Self-reported profits are not independently verified or proof of future returns.
- No real-money trading or automatic broker execution from these drafts.
